PATILNEO OTT DEMO — UPLOAD GUIDE

Files included:
- index.html
- style.css
- script.js
- movies.json
- player.html

How to use on GitHub from mobile:
1. Download and extract cineflix_ott_files.zip.
2. Open your GitHub repository.
3. Use Add file > Upload files.
4. Upload all five files from the extracted folder (not the zip itself).
5. Commit the changes.
6. Open Settings > Pages.
7. Select Deploy from a branch, branch main, folder /(root), then Save.
8. Open the website URL shown in Pages after it finishes publishing.

Notes:
- This is a front-end demo/prototype, not a complete commercial OTT backend or a native Android APK.
- The catalogue contains sample listings and placeholder poster images; it does not include real movies.
- Add only video URLs and poster assets you own or are licensed to distribute.
- GitHub Pages hosts static files; it does not provide video hosting, user accounts, subscriptions, or ad revenue by itself.
